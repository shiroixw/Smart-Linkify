# docs/superpowers

按时间归档的设计与执行记录，**不随代码演进回改**（保留当时的决策上下文）。

| 目录 | 内容 |
| --- | --- |
| `specs/` | 设计定稿：当时的目标、范围与约束 |
| `plans/` | 实施步骤：当时的执行清单 |
| `analysis/` | 问题分析报告与真实浏览器实测记录 |

## 现状以哪里为准

- **命令与工具链**：根目录 `README.md` 的「测试与质量门禁」一节
- **项目结构**：根目录 `README.md` 的「项目结构」一节
- **视觉与设计 token**：`extension/shared/tokens.css`、`website/css/style.css`

> 本文档里的命令（例如早期 spec 中的 `npm run lint:tsc`）可能已过时或从未存在。遇到不一致时，以根 `README.md` 为准，不要照抄历史任务书里的命令。
