# 图标说明

本目录的图标**全部由脚本生成，不要手工编辑 PNG**（手改会在下次重新生成时丢失）。

-   矢量源 & 尺寸由 `scripts/generate-icons.js` 顶部的 `DESIGN` / `GLYPH` 常量统一定义
-   重新生成：`npm run icons`（即 `node scripts/generate-icons.js`）

## 产物

| 文件 | 尺寸 | 用途 |
| --- | --- | --- |
| `icon.svg` | 128（矢量） | 设计真源，改色/改形从这里对照 |
| `icon16.png` | 16×16 | 浏览器工具栏（1x 屏） |
| `icon32.png` | 32×32 | 浏览器工具栏（2x 屏）/ HiDPI |
| `icon48.png` | 48×48 | 扩展管理页 |
| `icon96.png` | 96×96 | 扩展管理页 HiDPI（48dp @2x） |
| `icon128.png` | 128×128 | Chrome Web Store 详情、安装对话框 |
| `icon256.png` | 256×256 | 商店高分辨率展示（4K / @2x 详情页） |

## 设计规格（token）

-   **底**：圆角方块，圆角半径 = 尺寸 × 0.22，渐变 `#2563eb` → `#1e40af`（左上 → 右下）
-   **字形**：白色 `#FFFFFF` 描边，24 单位坐标系基准线宽 2；白色对底色的对比度约 5.5:1
-   **安全区**：字形包围盒占画布 58%（16px 70%、32px 64%，小尺寸放大以保可读性）
-   **描边下限**：任何尺寸下描边不低于 1.6 物理像素，避免细笔画消失

## 清晰度约定

-   每个尺寸**独立栅格化**（按有符号距离场逐像素解析求覆盖率），不是从大图缩放
-   新增尺寸只需改 `DESIGN.sizes` 并同步 `extension/manifest.json`
-   字形来自 [Lucide](https://lucide.dev) 的 `link`（ISC License），各尺寸共用同一字形以保持一致

## 常见问题

**为什么必须提供 32/96/256？** 扩展管理页在 2x 屏上按 48dp 渲染，需要 96 物理像素；只给 16/48/128 时浏览器只能缩放已有位图，会再次模糊。

**能直接用 SVG 当扩展图标吗？** 不能，`manifest.json` 的 `icons` 只接受位图，SVG 仅作设计源。
